# GAS

Landing page dengan tombol hijau bulat besar menuju artikel, dibangun menggunakan Next.js dan Tailwind CSS.

## Jalankan lokal

Gunakan Node.js 22 atau lebih baru.

```bash
npm ci
npm run dev
```

Buka http://localhost:3000.

## Build

```bash
npm run build
```

Hasil static export tersedia di folder `out/`.

## Mengganti artikel tujuan

Ubah `ARTICLE_URL` di `app/page.tsx`. Saat ini tombol membuka https://audi.pengajartekno.co.id/apk-penghasil-uang-langsung-ke-dana/.
